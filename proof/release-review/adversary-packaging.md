Fix: after extract, assert app package.json "main" exists, Resources/app/dist/renderer/index.html exists, dist-electron/{main,preload,receiver}.cjs exist, `lipo -archs` of the executable is exactly arm64. Test: export verifyDesktop and run it against a fixture app with main.cjs removed.
2. MEDIUM - no guard for the AppleDouble regression commit 9dacfcd fixed. Mutant: delete `--norsrc --noextattr --noacl` from the desktop ditto (l.221-230) -> `release-package --dry-run` still "10 checks passed", exit 0, `zipinfo -1 ...zip | grep -c -E '(^|/)\._|__MACOSX'` = 611. Cause: stray check (l.61-64) is a prefix test and `._x` under figma-drop.app/ passes; ditto extraction folds them back into xattrs. Fix: in verifyDesktop fail on any entry matching /(^|\/)(\._|__MACOSX\/|\.DS_Store$)/. Test: the mutant above must fail.
3. MEDIUM - release.yml upload names are a second hand-written copy of artifactNames. release.yml:86-92 vs scripts/release-artifacts.mjs:51-57. Existing tests assert artifactNames literals only. Seeded legit rename (plugin: `figma-drop-plugin-${version}` in code AND the test): `pnpm test:release` -> pass 7 fail 0, but /scratch/packaging/yml-names.test.mjs -> fail 2. Fix: the test in yml-names.test.mjs (parses the `gh release upload` step and the notice text and compares to artifactNames), or have the build job emit the file list and upload job use `release-artifacts/*`.

Fix: `diff -r apps/desktop/dist <app>/Contents/Resources/app/dist` + dist-electron + cmp package.json (I verified these are byte-identical after a fresh app:local) in verifyDesktop. Test: touch a dist file after packaging, expect failure.

7. LOW - checksums. Format is fine: `shasum -a 256 -c`, `sha256sum -c`, `gsha256sum -c` all OK (two-space "hash name"). The proof never exercises release mode (`--tag v0.0.0` happy path): I ran it, it works (2 zips + SHA256SUMS.txt + release-plan.json, 10/6 checks).
