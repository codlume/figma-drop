# Release proof

This folder holds the evidence that the release pipeline packages both products without publishing anything. All of it is synthetic and local. No tag, release, or upload was made. `proof/dmg/` holds the Finder screenshot and the raw signing evidence of the local DMG.

| File                  | What it shows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `local-proof.sh`      | The rerunnable local proof. Run `bash proof/release/local-proof.sh` from the repository root on an Apple silicon Mac. It needs no token, but `pnpm release:dry-run` needs `python3` 3.10 or later and PyPI, as `RELEASING.md` describes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `local-proof.txt`     | Its output at head `2c6a191`: the release tests, three rejected invocations, `pnpm release:dry-run`, `release-plan.json`, checksums, the plugin zip listing and its manifest compared with the source, and a walk through the unsigned DMG. The walk shows its `UDZO` format, `hdiutil verify`, a read-only mount, the volume entries, the `Applications` link, the embedded app's plist and signature, and that the DMG carries no signature. Then `spctl` rejects a quarantined copy of the app, and release mode refuses the ad-hoc build and writes no `SHA256SUMS.txt`.                                                                                                                                                                                                                                                                                                                                |
| `gates.txt`           | `pnpm typecheck`, `pnpm test`, `pnpm lint`, `pnpm fmt:check`, and `actionlint` at head `71c005b`, from the pull request that added the release workflow. It predates the DMG.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `check-workflows.mjs` | A policy check over `release.yml`, `release-dry-run.yml`, and `package-macos.yml`. It checks that the dry run is read-only, uses no secrets, uploads nothing, never calls `package-macos.yml`, installs dmgbuild first, and checks the release-mode refusal. In `release.yml`, `build` calls `package-macos.yml` read-only with the tag and the tagged commit and passes exactly the five secrets by name. In `package-macos.yml`, the `package` job reads the `release` environment, only the credential step sees the secrets, the gates and dmgbuild setup run before it, and the keychain cleanup always runs. It also checks the three stored artifacts and their retention, write access only on `release-please`, `release-pr`, and `upload`, pinned actions, a frozen lockfile, no expressions in `run:`, an idempotent install notice that names the DMG, and checksum verification before upload. |
| `mutate.mjs`          | Injects one defect per policy into a copy of the workflows and shows `check-workflows.mjs` catches each one with the matching assertion. It exits 1 if any defect passes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `workflow-policy.txt` | Output of both scripts at head `a945be2`. All 47 defects are caught.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `ci-dry-run.md`       | The **Release dry run** workflow run on pull request #15, which added the release workflow.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

The two workflow scripts need the `yaml` package, which the repository does not install. To rerun them, copy both into a scratch folder, run `npm install yaml@2.6.1` there, and run `node check-workflows.mjs <repo>` and `node mutate.mjs <repo>`.

`local-proof.txt` was recorded at `dfbdcc7`, after the workflow and docs commits. Its `pnpm test:release` passes all 61 tests, and its DMG is the one `proof/dmg/adhoc-dmg-evidence.txt` describes.

`spctl` rejects the extracted app, as it rejects every ad-hoc build. A release build is signed with a Developer ID and notarized instead, as the signing modes in `RELEASING.md` describe. Neither the release workflow nor the **Package macOS app** workflow has run the DMG build. Only a merged release PR on `main` starts the first, and a maintainer dispatches the second on `main`.
